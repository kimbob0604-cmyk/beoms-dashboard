# 소비재(화장품·식음료) 수출 탭 계획 (2026-11-10 작성)

바이오 탭이 "종목마다 가정치를 직접 관리하고 → 가치를 계산해 → 시총과 견준다"였다면,
소비재 탭은 **"종목마다 수출 흐름(어느 지역에서 무슨 품목이 나가는가)을 직접 관리하고 → 월별 통관 수출로
이번 분기 매출을 어림해 → 시총·POR 과 견준다"** 이다. 결정이 필요한 곳은 **[결정]**, 실측이 남은 곳은 **[확인 필요]**.

## 0. 참고한 것

### 나쁜양파(badonion.co.kr) — 구조만 참고 (`~/kbj/docs/research/badonion_structure.md`, 2026-10-21 확인)

- **종목별 흐름**: 종목 → (사업장 시군구, HS6 묶음, 상대국, 구분) = '흐름'. 흐름마다 근거(사업장↔공정, 타사 물량 혼입 같은 한계)와
  성격(회사 출하 / 업황 혼합)을 적는다. 월 금액 막대 + YoY 선, 단가·중량·일평균 탭.
- **맵핑 트렌드**: 매핑 종목 전부를 최신월 YoY·3개월 YoY 로 줄 세우기, 급등락만 보기.
- **급등 탐색**: 품목 단위로 갑자기 늘어난 수출 찾기.
- **국가별 조회**: 국가 → 품목 순위, 24개월 스파크라인, 전월·전년 대비, 관련 종목 칩.
- **실적 프리뷰**: 수출로 분기 매출을 추정해 컨센서스 대비 IN LINE / BEAT / MISS.
- **시장 점유율**: 수입국 통계에서 한국산 비중 (수입국 통계가 따로 필요).
- 나쁜양파의 데이터·리포트 본문은 쓰지 않는다. 원천은 관세청 공개 통계다.

  | 15100475 품목×국가 | 전국 × HS10 × 국가(228개국), 금액·중량 | 2023-01 ~ 2026-09 |

- 매핑: `config/knowledge/trade_map.yaml` 판 3 — 307종목·흐름 714. 텔레그램 수출입 채널 1년치 글을 근거로 만들고,

  실적 프리뷰(`preview.py`), 국가·산업 탭. 결과 JSON 은 `~/kbj-site/data/trade/` 에도 있다.

### KBJ 매핑을 소비재에 그대로 못 쓰는 이유 (확인한 빈 곳)

1. **화장품 핵심 품목이 빠져 있다.** 아모레퍼시픽·LG생활건강·한국콜마의 흐름이 '클렌징 제품(HS 3401) 전국' 하나뿐이고 셋의 YoY 가
   소수점까지 같다 — 회사 흐름이 아니라 같은 전국 시리즈를 나눠 붙인 것. 기초(330499)·색조(330410·330420)·헤어(3305)가 종목에 안 붙어 있다.
2. **시군구 과거치가 12개월이라 YoY 가 안 나온다.** 삼양식품·농심·에이피알·코스맥스·KT&G 등이 '겹치는 기간 부족'(yoy 없음) 상태.
   하루 호출 한도 때문에 최근 12개월 창만 받아 둔 것 → 소비재 HS6 만 5년 백필하면 풀린다.
3. **유니버스가 좁다.** 실리콘투·브이티·달바글로벌·코스메카코리아·씨앤씨인터내셔널·클리오·펌텍코리아·오리온·파마리서치 등이 없다.
4. 삼양식품 실적 프리뷰가 '신뢰도 낮음·추정 없음' — 2번 때문에 과거 분기와 맞출 수출 값이 없다.

### 데이터 제약 (계획이 여기에 맞춰져 있다)

- **10일 단위 속보는 품목(HS) 단위로 못 받는다.** API 의 10일 잠정치는 전체·10대 품목·10대 국가뿐이다(KBJ `probe_results.md` F2).
  화장품·라면의 "1~10일 수출"은 이 경로로는 불가 → 이 탭은 **월 단위(매월 15일경 전월 확정)** 가 기본이다.
- **2026-09-01부터 시군구 통계가 줄었다.** K-stat·TRASS 가 시군구 기준 HSK 10단위와 중량을 비공개로 바꿨고, 시군구는 HS 2·4·6단위 **금액만** 남았다
  ([스마트투데이](https://www.smarttoday.co.kr/ko-kr/articles/111033)). 우리가 쓰는 공공데이터 API 는 원래 HS6·금액만이라 영향이 없다.
  다만 **시군구 단가(금액÷중량)는 볼 수 없다** → 단가·물량 분해는 전국 HS10 에서만 한다.
- 시군구 = 수출 신고인의 소재지다. 공장이 아니라 본사·물류센터·무역상 주소로 잡히는 경우가 많다(예: `330499` 최신월 1위 강남구, 2위 인천 제물포구,
  3위 송파구). 한 시군구에 여러 회사가 섞이므로 흐름마다 '회사 출하 / 업황 혼합'을 구분해 적는다.
- 해외 공장 매출은 한국 수출에 안 잡힌다(오리온 중국·베트남·러시아, 농심 미국·중국, CJ제일제당 미국, 코스맥스·콜마 해외 법인).
  이런 회사는 수출이 매출의 일부만 설명한다 → 종목마다 '수출이 설명하는 매출 비중'을 함께 보여 준다.

## 3. 수집 (`collect_trade.py` → `db/trade.db`)

- **[결정] 수집 경로.** (가) 이 대시보드가 관세청 API 를 직접 부른다 — SQLite, 도커 불필요, 지금 구조와 같다.
  (나) KBJ 의 Postgres 를 읽기만 한다 — 코드가 적지만 도커가 떠 있어야 하고 KBJ 매핑표에 HS6 를 추가해야 시군구가 받아진다.
  **(가)를 권한다.** 키는 `config.py` 가 이미 다른 프로젝트 `.env` 를 읽는 방식 그대로 `~/kbj/.env` 의 `KBJ_DATAGO_KEY` 를 재사용하고,
  처음 한 번만 KBJ DB 에서 소비재 품목 과거치를 옮겨 와 호출을 아낀다.
- 호출량: 시군구는 '시도 × HS6 × 12개월 창'이 한 번. HS6 약 35개 × 시도 17 × 5년 = 약 3,000회 → 하루 한도(9,500/데이터셋) 안에서 하루에 끝난다.
  매월 갱신은 35 × 17 = 약 600회. KBJ 와 같은 키를 쓰므로 KBJ 의 월 수집과 겹치지 않게 16일 새벽에 돈다.
- 받는 것: 전국 HS10 월(금액·중량), 전국 HS10 × 국가 월, 시군구 × HS6 월(금액). 환율(원/달러 월평균)은 한국은행 ECOS 또는 KBJ 값.
- 갱신 주기: 매월 15일경 전월 확정. 정정이 있으므로 최근 3개월은 매번 다시 받는다. `daily.py` 는 16~20일에만 수집을 시도하고 나머지 날은 빌드만.
- 속보 보완 **[확인 필요]**: 매월 1일 산업부 수출입동향 보도자료에 화장품·농수산식품 월 수출액이 나온다(15일보다 2주 빠른 총액).
  PDF 표를 읽어 '업황 속보' 한 줄로 쓸 수 있는지 실측한다. 품목 단위 10일 값은 무료 경로가 없다.

## 4. 종목 ↔ 흐름 매핑 (`consumer_assets.json`, 바이오의 `bio_assets.json` 자리)

```json
{"code": "003230", "name": "삼양식품", "group": "식음료",
 "export_share": 0.8,                      // 매출 중 한국발 수출 비중 (사업보고서, 근거 필수)
 "flows": [
   {"id": "s1", "label": "라면 — 밀양·원주·익산", "kind": "sigungu", "hs6": ["190230"],
    "regions": ["밀양시", "원주시", "익산시"], "nature": "company", "weight": 1.0,
    "basis": "사업보고서 생산설비 소재지 (접수번호 …)", "caveat": "원주에 타사 물량 일부"},
   {"id": "n1", "label": "라면 — 전국", "kind": "national", "hs10": ["1902301010"], "nature": "mixed", "weight": 0}
 ],
 "reviewed": false}
```

- **초안 도구(`consumer_draft.py`, 바이오의 `bio_draft.py` 자리)**: 종목 하나를 주면
  ① KBJ 매핑에 있으면 그 흐름을 가져오고, ② DART 사업보고서의 사업장 소재지에서 시군구를 뽑고,
  ③ 그 시군구의 소비재 HS6 수출 순위와 ④ 후보 흐름별 '분기 수출 ↔ 분기 매출' 상관·시차를 계산해 표로 보여 준다.
  사람이(Claude 가) 보고 흐름을 정해 `reviewed: true` 로 바꾼다. 상관이 낮으면 '업황 혼합'으로 둔다.
- 흐름 성격: `company`(그 시군구 물량 대부분이 이 회사) / `mixed`(여러 회사가 섞임 — 강남구 기초화장품 등) / `affiliate`(자회사·관계사).
- ODM·유통사는 직접 수출이 적다(코스맥스·콜마는 고객사가 수출, 실리콘투는 자기 이름으로 수출). 이런 종목은
  '고객사 묶음 흐름'(업황 혼합)과 회사 흐름을 따로 두고, 화면에 "간접 수출"이라고 적는다.
- 탐방 노트와 연결: 탐방 탭(`visits.json`)에 그 종목 노트가 있으면 카드에 건수와 최근 제목을 붙인다. 매핑 근거를 찾을 때도 쓴다
  (예: 탐방 노트에 "수출은 ○○공장에서" 같은 문장).
- 설정 검증 테스트(`tests/test_consumer_config.py`): 코드·이름 일치, HS 자릿수, 시군구가 지역표에 있는지, 가중치 합, 근거 유무.

## 5. 계산 (`consumer.py` 순수 함수 + `build_consumer.py` → `public/data/consumer.json`)

- 흐름 월 시리즈: 금액(USD·원화), YoY, 3개월 합 YoY, **일평균 YoY**(조업일수 보정), 전국 흐름은 단가(금액÷중량)·물량 YoY 까지.
- 분기 누적: 진행 중 분기는 '있는 달 평균 × 3'(추정 표시). 달이 하나뿐이면 추정하지 않는다.
- **실적 프리뷰**: 과거 8~12개 분기의 (분기 수출 원화, 분기 매출) 회귀 → 이번 분기 매출 추정 → 컨센서스 대비
  BEAT(+5% 초과) / IN LINE / MISS(−5% 미만). 표본 수·R²·시차로 신뢰도(높음·보통·낮음)를 매기고 낮으면 판정을 내지 않는다.
  분기 매출은 DART(이미 `collect_dart.py` 가 받는 잠정실적·분기 재무), 분기 컨센서스는 `cns_quarter`.
- **시총 기준 표시**: 종목 카드는 시총과 POR 표(`U.porTable`)가 먼저다. 프리뷰가 있으면
  "수출 추정 매출 × 직전 4분기 영업이익률 → 추정 영업이익 → 이 시총이면 POR 몇 배"를 한 줄로 덧붙인다(어림값 표시).
- 업황판: 품목 묶음별 전국 수출(월·YoY·일평균 YoY), 국가별 스택(미국·중국·일본·EU·동남아·중동·기타), 단가·물량 분해.
- 급등 탐색: 소비재 HS6 × 시군구에서 3개월 합 YoY 가 크게 뛴 곳(최소 금액 조건). 매핑된 종목이 있으면 칩, 없으면 '미매핑' —
  새 브랜드·새 수출 거점을 찾는 용도다.

## 6. 화면 (`public/consumer.html`, 탭 이름 '소비재')

1. **업황 카드 줄**: 기초화장품 / 색조 / 라면 / 과자·빙과 / 김 / 음료·주류 / 담배 — 최신월 금액, YoY, 3개월 YoY, 24개월 스파크라인.
   누르면 아래에 국가별 스택 차트와 단가·물량 분해.
2. **종목 표(맵핑 트렌드)**: 종목 | 시총 | 내년 POR | 수출 최신월 YoY | 3개월 YoY | 수출 설명 비중 | 프리뷰 판정 | 12개월 스파크라인.
   묶음 칩(화장품 브랜드·ODM·식음료…), 급등락만, 정렬.
3. **종목 상세(행을 펼침)**: POR 표 → 흐름 카드(지역·품목·성격·근거·한계) → 월 금액 막대 + YoY 선(금액 / 일평균 / 단가 탭)
   → 분기 수출 vs 분기 매출 점 차트(실제·추정) + 프리뷰 문장(규칙 템플릿) → 탐방 노트·최근 리포트 링크.
4. **급등 탐색 표**와 **다음 일정**(15일 확정, 1일 산업부, 실적 발표일).
5. 종목 이름을 누르면 기존 종목 패널이 열리고, 패널에도 '수출 흐름' 한 줄 요약을 넣는다.

공개 여부: 관세청 통계는 이용 제한이 없고 매핑은 직접 만든 것이라 공개해도 된다. 다만 컨센서스가 들어가는 프리뷰 판정은
지금 대시보드의 다른 탭과 같은 기준으로 둔다. **[결정]** 처음에는 `publish_hold.txt` 로 보류했다가 검수 뒤 공개.

## 8. 그 밖에 붙일 만한 기능 (우선순위 순)

0. **탐방 노트 카드에 종목 차트 + 탐방일 표시** — 아래 9절. 소비재 탭보다 먼저 할 수 있다(반나절).
1. **탐방 노트 요약 예약 작업** — `visit_notes.py pending/add` 는 만들어 뒀다. 전략 트래커의 `strategy-notes` 처럼 평일 한 번
   새 노트를 읽고 두세 문장 요약을 쓰게 한다. 지금 요약 칸이 전부 비어 있다.
2. **종목 패널에 탐방 노트·수출 흐름 줄** — 어느 탭에서 종목을 열든 "탐방 노트 3건(최근 11/4) · 수출 3개월 YoY +32%"가 보이게.
3. **오리온식 월별 실적 공시 추적** — 해외 법인 매출을 매달 공시하는 회사(오리온 등)는 수출 통계 대신 공시 숫자로 같은 차트를 그린다.
4. **홈·리포트 탭의 목표가 → 목표 시총** — 시총 기준 전환에서 남겨 둔 두 곳.
5. **수출 채널 글 연결(선택)** — 본인 텔레그램 로그인이 생겼으므로 수출입 채널 글을 종목별로 '제목·링크만' 모을 수 있다.
   숫자·본문은 옮기지 않는다(KBJ 와 같은 원칙).
6. **브랜드 수요 보조 지표(선택, 실측 필요)** — 네이버 데이터랩·구글 트렌드 검색량, 방한 외국인·면세점 매출(월), 온라인 해외 직접 판매(분기, KOSIS).
   수출과 엇갈릴 때 해석을 돕는다. 아마존·올리브영 순위 수집은 약관 문제가 있어 넣지 않는 쪽을 권한다.

## 9. 탐방 노트에 종목 차트 (2026-11-10 추가 — 사용자 요청)

**상태: 2026-11-10 완료** — (가) 방식으로 구현했다(`collect_visits_chart.py`, `plot.js` marks, `visit.js`). 아래는 당시 계획.

탐방 탭의 종목 카드마다 그 회사 차트를 넣어 "탐방이 차트의 어느 자리에서 있었나"를 바로 보게 한다. 소비재 탭과 별개로 먼저 할 수 있다.

### 확인한 것 (2026-11-10)

- 네이버 증권 일봉(`fchart.stock.naver.com/sise.nhn?symbol={코드}&timeframe=day&count=500`)은 종목 코드로도 열린다.
  코스맥스로 시험해 2024-10-22 ~ 오늘(장중 값 포함) 500거래일이 왔다. 지수용으로 이미 쓰는 호출(`collectors/naver.py` 의 `parse_fchart`)을 그대로 쓴다.
- 종목 패널용 차트 파일(`data/chart/{코드}.json`)은 탐방 종목 265개에 모두 있지만 최근 약 50~260거래일뿐이라, 1년 전 탐방까지 덮지 못한다 → 탐방 종목만 따로 길게 받는다.
- 그리기 도구(`plot.js`)에는 날짜 표시(세로선·점) 기능이 없다 → 추가한다.
- 과거 가격 DB(`db/history.db`)에 날짜별 실제 시총이 있다(탐방 '당시 시총'에 이미 쓰는 값).

### 만들 것

- **수집** `collect_visits_chart.py`: 탐방 노트가 있는 종목만(지금 265개, 노트만 보면 215개) 네이버 일봉 500거래일 → `public/data/vchart/{코드}.json`.
  하루 한 번, 종목당 한 번 호출(0.1초 간격이면 30초 안팎). 실패한 종목은 직전 파일을 그대로 둔다.
- **화면**: 종목 카드의 POR 표 옆(좁은 화면에서는 아래)에 작은 차트.
  - 일봉 종가 선(또는 캔들) + 거래량, 기간 6개월 / 1년 / 2년.
  - **탐방일 표시**: 노트가 올라온 날에 세로 점선과 점. 점에 마우스를 올리면 그 노트 제목, 누르면 아래 노트로 이동.
    같은 날 노트가 여럿이면 점 하나에 건수.
  - **축은 시총**(주가 아님): 종목 패널과 같은 환산(주가 × 지금 주식 수). 탐방일 점의 값은 과거 DB 의 그날 실제 시총을 쓴다.
  - 차트 아래 한 줄: "첫 탐방(○/○) 뒤 시총 +○○% · 최근 탐방 뒤 +○○%", 그리고 '네이버 증권에서 보기 ↗' 링크.
- `plot.js` 에 표시 기능 추가: `marks: [{i, label, color}]` — 다른 탭(소비재 탭의 수출 발표일·실적 발표일 표시)에서도 쓴다.

### [결정] 차트를 어떻게 가져올지

| 방식 | 장점 | 단점 |
|---|---|---|
| (가) 네이버 **일봉 데이터**를 받아 직접 그린다 — 권장 | 탐방일을 차트에 찍을 수 있다. 시총 축으로 바꿀 수 있다. 다크 모드·기존 화면과 같은 모양 | 수집 한 단계 추가 |
| (나) 네이버 **차트 이미지**를 그대로 붙인다 | 가장 간단하고 장중 실시간 | 탐방일 표시 불가, 주가 축만, 다크 모드에서 흰 그림. 예전에 종목 패널이 이 방식이었다가 직접 그리기로 바꿨다 |
| (다) 네이버 대신 이미 있는 과거 가격 DB 로 그린다 | 추가 호출 없음, 실제 시총 | 오늘 장중 값이 없고 KRX 공개 전 날은 비어 있다 |

(가)를 기본으로 하고, 네이버가 응답하지 않는 종목만 (다)로 채운다.

### 끝났다는 기준

- 탐방 노트가 있는 종목 전부에서 차트가 뜨고, 가장 오래된 노트(1년 전)까지 표시가 찍힌다.
- 표시를 누르면 해당 노트로 이동한다. 시총 축 값이 카드의 '당시 시총'과 맞는다(증자 종목은 차이를 화면에 고지).
