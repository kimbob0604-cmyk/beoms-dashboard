# 위클리·데이터 갱신 방식 개편 — 운용사 기준

2026-11-28 조사. 읽은 것: 노션 `큐빅 시니어 / 위클리` 아래 내 위클리 12편(9월 1주~11월 3주), `남들 위클리` 16편, 스킬 `weekly-report`·`weekly-market-data`, 야데니 [YRI Selected Daily Markets](https://yardeni.com/charts/global-financial-markets/overview-outlook/yri-selected-daily-markets) 57개 차트.

목표는 두 가지다.
1. 지금 위클리를 운용사(인턴·RA·주니어 애널리스트)에서 바로 쓰는 형식으로 바꾼다.
2. 야데니식 차트를 데이터 갱신 흐름에 넣는다.

## 1. 내 위클리는 지금 어디까지 왔나

### 변천

| 시기 | 편 | 모양 | 차트 |
|---|---|---|---|
| 1기 | 9월 1주 | 종목 하나(코인베이스) 이야기 + 시장 복기, 비중 숫자 공개(COIN 80%) | 약 10장 |
| 2기 | 9월 2~4주 | 이벤트 해설 → 9월 3주부터 번호 고정 틀(결론·복기·핵심 변화·섹터·매매·대응·일정) | 24~27장 |
| 3기 | 10월 1~3주 | 공부·딥다이브형(모듈·전공정, 광통신, 지씨지놈·LQDA 목표 시총). 10월 3주가 약 2만 자로 가장 김 | 많음 |
| 4기 | 10월 4주~11월 3주 | 시스템형: BUY/SELL/WATCH, 국면 판독 5축, 노출 사다리(0·⅓·⅔), 채점표, IB 트리거, 부록 | 약 15장 |

### 잘하고 있는 것 (남들 16편과 비교해도 드묾)
- 결론이 맨 위에 있고, 다음 주는 `조건 → 행동`으로 쓴다.
- 지난주 조건을 전부 채점하고(적중·부분·오답·미발생) 틀린 이유를 규칙으로 바꾼다. 남들 중 채점하는 사람은 준영·'~주 기록' 시리즈·Bee 11-1 정도다.
- 판단마다 BUT 반론을 붙인다.
- 지표가 사이트(범스매크로)에서 매일 자동으로 쌓여서, 위클리 숫자를 손으로 찾지 않는다.

### 문제
1. **개인 매매 일지와 시장 리포트가 한 문서에 섞여 있다.** 11월 3주만 봐도 애프터마켓 테마 추격 복기(에스엠·키다리스튜디오)와 연준·크레딧 국면 판독이 같은 페이지에 있다. 운용사에서는 둘이 다른 문서다(하우스 뷰 / 포트폴리오 리뷰).
2. **벤치마크가 없다.** 노출 0·⅓·⅔는 절대수익 언어다. 공모 롱온리 펀드는 주식 편입 비율을 크게 못 바꾸고, 벤치마크(KOSPI·KOSPI200) 대비 섹터·종목 비중(OW/UW)과 현금 몇 %로 말한다. 노출 0은 롱온리에선 가능한 선택지가 아니다.
3. **포트폴리오 숫자가 없다.** 비중·진입가·손익·벤치마크 대비 초과수익이 빠져 있다. 10월 4주에 매매 로그 표를 `[입력 필요]`로 두고 그 뒤 사라졌다.
4. **길다.** 결론 블록만 해도 굵은 줄 7개 + 포지션 + 토글 2개 + 차트 1장이고, 본문은 차트 약 15장 + 5축 판독이다. 팀 회의에서 PM이 읽는 분량은 1페이지다.
5. **매주 조건이 새로 생긴다.** 채점 조건 4 → 10 → 15 → 12개. 상시 규칙(노출 사다리, 숏커버 규칙)과 이번 주 이벤트 조건이 섞여서, 어느 규칙이 작동했는지 사후 해석이 갈린다(10월 5주: 5,500 이탈 축소 규칙이 SK하이닉스 실적 이틀 전에 걸림).
6. **자체 지표 비중이 크다.** 바닥 신호판·매도 소진 점수가 노출 결정에 직접 연결되는데, 표본이 1.5년이거나 '아무 날'과 차이가 작다는 점을 스스로 부록에 적어 두었다.
7. **리스크 한도가 없다.** 종목당 최대 비중, 손절 폭, 유동성 기준이 사이징과 연결돼 있지 않다.
8. **컨센서스·리비전이 약하다.** 대부분 자체 추정이다. 범스보드에 리비전 탭이 있는데 위클리와 이어져 있지 않다.
9. **차트가 재현되지 않는다.** 위클리 차트(`k_score`, `k_bottom` 등)를 만드는 고정 스크립트가 저장소에 없다. 매주 세션에서 새로 그린다. 같은 차트가 주마다 조금씩 달라질 수 있다.

### 복기에서 반복된 실수 (12편 채점 기준)
- 이벤트 숫자는 맞혔는데 '좋은 숫자 → 주가 상승'으로 이었다가 틀림(엔비디아 가이던스 상향 → 주간 −22.9%, 앤트로픽 흥행 → AI 바스켓 투매).
- 급등 뒤·이벤트 직전 진입(피델릭스, 삼성전기, 한화비전 +32% 뒤 BUY → −25.7%, 애프터마켓 상한가 추격).
- 가격 규칙이 너무 일찍 걸리는 휩소(5,500 이탈 축소, 지씨지놈 축소 기준).
- 보유 종목이 개별 악재 없이 시장 베타로 −24% — 가격 기준 대응이 없음.

공통 뼈대: 결론 한두 줄 → 매크로 3종(10년물·유가·FOMC/물가) → 국장·미장 요약 → 다음 주 일정 → 이벤트별 조건부 행동 → 매매·포트.

**가져올 장치 다섯 개**
1. 맨 위 `결론 + 포지션 + 근거 3개` 한 블록(기웅·기록 시리즈).
2. 이벤트별 3구간 시나리오표: 숫자 경계 + 행동(11/22, 기웅 PCE).
3. 콜 번호 채점표: 번호·결과·원인·폐기 조건(준영·기록 시리즈). 나는 이미 하고 있으니 **누적 적중률**만 더하면 된다.
4. 1차/2차 단계 진입과 조건 점검표 N/M(기록 시리즈). 내 노출 사다리와 같은 생각인데, 표 한 장으로 줄인 점이 낫다.
5. 밸류에이션 민감도 표: 가정·산식을 적고 멀티플·조달 방식별로(Hyundo).

|---|---|---|

지원처가 공모 운용사인지 헤지펀드인지에 따라 위클리 포지션 칸의 언어가 바뀐다. 아래 개편안은 **BM 대비 모의 펀드**를 기본으로 두고, 넷 익스포저를 한 줄 덧붙이는 식으로 둘 다 설명할 수 있게 했다.

### 실무에 들어가면 바뀌는 것
- **개인 매매가 제한된다.** 금융투자회사 임직원은 자기 명의·지정 계좌 하나로만 매매하고 매매 내역을 회사에 알려야 한다(자본시장법 제63조, 세부는 회사 내부 규정). 그래서 위클리의 '매매 복기'는 실계좌보다 **모의 펀드** 쪽으로 옮겨 두는 편이 이어 가기 쉽다.
- **회사 자료를 밖으로 못 가져간다.** 블룸버그·FnGuide·내부 리포트 숫자를 개인 사이트·노션·공개 깃허브에 올리면 안 된다. 범스보드·범스매크로는 공개 출처로만 돌고 있으니 개인 공부용으로 그대로 두면 된다.
- **공개 채널은 확인이 필요하다.** 공개 사이트·텔레그램 공개 채널에 종목 의견을 계속 내는 건 입사 전에 컴플라이언스에 물어볼 일이다. 비공개 전환 스위치를 미리 만들어 두면 편하다.
- **툴이 바뀐다.** 지금 사이트로 하던 일을 회사 툴로 옮기면 대략 이렇게 대응된다: 수급·체결 → 인포맥스·CHECK, 컨센·실적 → FnGuide DataGuide, 차트·비율 → 블룸버그(G·GP), 리포트 → 회사 리서치 포털. 화면 이름보다 '무엇을 매주 같은 기준으로 뽑는가'를 익혀 두는 게 옮겨 간다.

## 4. 새 위클리 양식

두 층으로 나눈다. 1층은 사람이 쓰고, 2층은 대부분 스크립트가 만든다.

### 1층: 위클리 메모 (1페이지, 1,500자 안팎, 차트 3장)

```
# Beomjun Weekly 12월 1주차 (11/30~12/4)

## 1. 한 줄 결론 (3줄)
- 시장: {이번 주를 움직인 것 → 내 판단}
- 포지션: 모의 펀드 주식 {x}% (BM 대비 {OW/UW 섹터 2개}) · 넷 {y}%
- 다음 주 관건: {이벤트 1개 + 숫자 경계}

## 2. 모의 펀드 (표 1개)
| | 이번 주 | 연초 이후 | BM(KOSPI200) | 초과 |
| 상위 5종목 · 비중 · 주간 수익률 · 기여
| 섹터 OW/UW 3줄

## 3. 바뀐 판단 (최대 3개)
- {주제}: 지난주 → 새 증거(기대 대비) → 지금. BUT {반론}

## 4. 다음 주 조건 → 행동 (최대 3개, 3구간 표)
| 이벤트 | 아래 | 기본 | 위 |  ← 숫자 경계와 행동
```

규칙
- 차트는 3장만: ① 국내·글로벌 주간 등락 ② 이번 주 판단을 바꾼 지표 1장 ③ 모의 펀드 vs BM 누적.
- 상시 규칙은 위클리에 매주 다시 쓰지 않는다. `규칙집` 페이지 하나에 두고 바뀔 때만 '규칙 변경' 한 줄을 남긴다.
- 이번 주 조건은 **3개 이하**. 지금처럼 12~15개를 걸면 채점은 쉬워져도 판단은 흐려진다.

### 2층: 부록 (토글, 대부분 자동)

| 부록 | 내용 | 만드는 곳 |
|---|---|---|

## 5. 데이터 갱신 흐름 바꾸기

### 지금
- 사이트 다섯 개(범스보드·범스터디·범스매크로·범스바이오·범스컨슈머)는 클라우드·맥 예약으로 매일 갱신된다.
- 위클리를 쓸 때는 `weekly-market-data` 스킬이 네이버에서 숫자를 다시 받고, 차트는 그 세션에서 즉석으로 그린다.
- 같은 숫자를 두 곳에서 받으니 사이트 값과 위클리 값이 어긋날 수 있다.

### 바꿀 것
1. **위클리 숫자는 사이트 DB에서만 읽는다.** 범스매크로 `db`와 범스보드 `db/history.db`가 원천이다. 네이버 재수집은 사이트에 없는 값만.
2. **`weekly_pack.py` (범스매크로 폴더)**: 금요일 미국장 마감 뒤 한 번 돌면
   - 차트북 PNG(고정 번호, 아래 §6 차트 포함), 숫자 표 `weekly_pack.json`
   - 지난주 조건 채점 초안(판단 로그에서 조건별 실제 값 채움)
   - 모의 펀드 주간·누적 수익률, BM 대비, 섹터 기여
   를 `~/Beom's Macro/weekly/{YYMMDD}/`에 만든다. 클라우드 예약(토 07:00)에 얹을 수 있다.
3. **판단 로그**: 날짜 · 판단 · 조건(숫자) · 마감일 · 결과 · 판정 · 종류. 매일 아침 보고 볼 때 한 줄씩 적고, 위클리 채점과 월간 적중률이 여기서 나온다. 위치는 노션 DB(손으로 적기 쉬움) 또는 범스매크로 JSON(자동 채점 쉬움) 중 고른다.
4. **모의 펀드 장부**: 종목 · 비중 · 진입일 · 진입가, BM = KOSPI200. 매매는 '다음 날 시가 체결'로 기록해 사후 편향을 막는다.
5. **포워드 P/E**: FactSet Earnings Insight 주간 PDF(금요일 발행, 무료)에서 S&P500 12개월 선행 P/E·EPS·섹터별 P/E를 뽑아 주 단위로 쌓는다. 11/20 판 PDF가 받아지는 것까지 확인함. 운용사 리포트가 가장 많이 인용하는 숫자라 야데니의 포워드 P/E 차트를 대신한다.

## 9. 정할 것

1. **야데니 방식**: ① 차트 아이디어만 가져와 공개 데이터로 다시 그리고 원본은 링크(권장) ② 맥 로컬 화면에서만 원본 이미지를 띄워 보기(저장·공유 안 함, 약관상 애매) ③ 원본을 받아 위클리에 붙이기(약관 위반 소지, 비권장).
2. **목표 운용사 유형**: 공모 롱온리(BM 대비 OW/UW) / 헤지펀드(넷 익스포저) / 둘 다.
3. **모의 펀드 BM과 시작 구성**: KOSPI200 권장. 시작 종목·비중은 직접 정해야 함.
4. **판단 로그 위치**: 노션 DB / 범스매크로 JSON.
5. **위클리 공개 범위**: 학회 노션에 1층만 올리고 부록·개인 일지는 비공개로 둘지.
