# Study 재정리 계획 — 키워드(백과사전) 분류 → 섹터 × 날짜 흐름 (2026-11-19, 계획 단계)

## 0. 지금 구조와 문제

- **구조**: 섹터(11개) → 주제 노드(시장 지도·HBM·DRAM·밸류에이션 …) → 카드. 리포트 여러 건을 주제별로 녹여 "겹치면 한 번만, n/m 동의"로 합쳤다.
  섹터 종합 문서 12개(카드 약 1,450장), 리포트 69건(`study/reports.json`, 표지 발간일 10/26~11/19), 책·교재 2권(반도체 책·바이오 독학 노트).
- **잘 되는 것**: 한 주제를 한 번에 공부하기 좋다(합의·견해 차이·숫자 맞대기).
- **문제**
  1. **시간이 사라진다.** 10/26 신한과 11/16 키움이 한 카드에 섞여, "언제 무엇이 바뀌었나"가 안 보인다.
     예) SK하이닉스 목표주가를 발간일 순으로 놓으면 11/2~4 KB 350만·한투 320만·iM 230만 → 11/10~12 DS 264만·메리츠 320만·하나 280만(하향) → 11/16 키움 180만(하향).
     2028 가격도 11/10 DS −25% → 11/16 키움 −54%로, 11월 중순부터 신중론이 나온다. 지금 화면에서는 이 흐름을 읽을 수 없다.
  2. **새 리포트가 들어올 때마다 기존 카드를 고친다**(n/8 → n/9, 문구 수정). 매일 정리 비용이 크고, 여러 세션이 같은 JSON 을 고치다 덮어쓰는 사고가 났다(11/19 반도체).
  3. **리포트 한 건을 통째로 보는 곳이 없다.** 그 리포트의 결론·목표가·그림이 여러 주제에 흩어져 있다.

## 1. 바꿀 구조 (권장안)

섹터 아래 첫 화면을 **흐름(날짜)** 으로 바꾸고, 지금의 주제 종합은 **'주제' 탭**으로 남긴다. 카드는 버리지 않는다 — 같은 카드를 두 길로 본다.

```
Study › 반도체
  [흐름]  [주제]  [교재]                     ← 섹터 첫 화면의 탭
  흐름
    · 섹터 흐름 카드 (자동): 발간일 순 목표주가·2027 이익 추정·시각(낙관/신중) 점 그래프, 이번 주 바뀐 것
    · 11월 3주 (11/16~)   키움 「봄이 오면」 신중 · SK 목표 180만(하향) · 2028 DRAM −54%  → 리포트 보기
    · 11월 2주 (11/9~15)  하나 · 메리츠 · 유안타 · DS — 한 줄씩
    · 11월 1주 (11/2~8)   KB · 한투 · iM · BNK · IBK · NH
    · 10월 4주            신한(소재) · LS(인터커넥트) · 삼성(후공정)
  리포트 보기 (한 건)
    · 머리: 하우스·애널리스트·표지 발간일·쪽수·의견·톱픽·목표가·시각
    · 한 줄 결론 / 핵심 주장 5~10 / 그 리포트의 그림 카드들(이미 잘라 둔 것) / 이 리포트만의 시각
    · "직전 대비": 같은 섹터의 앞선 리포트와 다른 점(목표가·이익·2028 시각), 동의한 합의 카드 링크
  주제 (지금 구조 그대로)
    · 이름만 "2027 전망 종합 — 11/19 기준" 처럼 기준일을 붙인 스냅샷
  교재
    · 반도체 책(semi-oneday), 바이오 독학 노트처럼 날짜가 의미 없는 것
```

- 다른 안과 비교
  - **주제를 없애고 날짜만**: 공부용 정리가 사라진다. 비추천.
  - **주제 노드 안에서 카드만 날짜순 정렬**: 구현은 쉽지만 "리포트 한 건 보기"와 "섹터 흐름"이 안 생긴다. 1단계 임시안으로는 가능.

## 2. 데이터 바꿀 것

1. **`study/reports.json` 을 뼈대로 키운다** (지금은 house·analyst·title·date 4개 필드).
   - 추가 필드: `sector`(여러 개 가능)·`doc`(들어간 종합 문서)·`posted`(텔레그램 올린 날)·`pages`·`stance`(낙관/중립/신중)·`call`(의견·톱픽·목표가 목록)·`summary`(한 줄 결론)·`claims`(핵심 주장 5~10)·`digest`(요약 파일 경로).
   - 채우는 법: 이미 있는 요약(digest)에서 뽑는다. 반도체 13 · 전력 13 · 전략 10 · 산업재 5 · NH 8 · 미디어 4 · 바이오 4 · 소비재 2 · 2차전지 1(나머지 7건은 첫 세션 작업 폴더에 있었음 — 다시 만들거나 카드에서 역추출).
2. **카드에 리포트 키를 단다** — `rep: ["rg-14687"]`.
   - 그림·표 카드: 이미 crops.json 의 `pdf` 로 알 수 있다(자동).
   - 글·차트·계산 카드 677장 중 507장은 `src`("신한 p.18", "메모리 전망 8곳")가 있다 → 하우스 이름·쪽을 리포트 키로 바꾸는 변환기로 자동 + 남는 것만 손으로.
3. **빌드가 흐름 목록을 만든다** — `build_study.py` 가 `public/data/study/flow/<섹터>.json` 생성:
   주(월요일 시작)별 리포트 목록 + 리포트별 카드 위치 + 흐름 차트용 숫자(목표가·이익 추정·시각). 사람 손이 안 가는 부분.
4. **흐름 차트용 숫자**: `call`·`stance` 와 섹터별 핵심 숫자 1~3개(반도체 = 2027 영업이익·목표주가·2028 DRAM 가격 / 2차전지 = AMPC 포함 이익 / 전력 = 미국 데이터센터 GW …)를 리포트마다 적어 두면 점 그래프가 자동으로 그려진다.

## 3. 화면 바꿀 것 (`public/js/study.js` — 원래 세션 소관)

- 섹터 첫 화면에 탭 `흐름 | 주제 | 교재`, 기본 `흐름`.
- 주소: `?n=semi/flow`(섹터 흐름), `?r=rg-14687`(리포트 보기). 지금 주소(`?n=semi/outlook27/hbm`)는 그대로 둔다(링크 안 깨짐).
- 리포트 보기 화면: 머리 + 결론 + 그 리포트 카드(다른 주제에 있는 카드를 끌어와 다시 그림) + "주제에서 보기" 링크.
- 그림 제목에 이미 붙는 발간일(YY.MM.DD)을 누르면 그 리포트 보기로.

## 4. 매일 정리 절차 바뀌는 점 (`docs/study-daily.md`)

- 지금: 새 리포트 → 종합 문서의 합의·견해 차이 카드를 고침(무겁고 충돌 위험).
- 바꾼 뒤: 새 리포트 → **그날은 리포트 보기만 만든다**(reports.json 한 줄 + 그림 자르기 + 요약). 흐름 화면에 바로 나온다.
  주제 종합(n/m 갱신)은 **주 1회**(예: 토요일) 몰아서 하고, 스냅샷 기준일을 올린다.
- 효과: 매일 작업이 가벼워지고, 한 섹터 JSON 을 여러 세션이 동시에 고치는 일이 줄어든다.

## 6. 정할 것

1. **묶음 단위**: 주(권장) / 월 / 리포트 한 건씩 나열.
2. **주제 종합의 운명**: 탭으로 남기고 주 1회 갱신(권장) / 그대로 매일 갱신 / 동결(새 리포트는 흐름에만).
3. **기준 날짜**: 표지 발간일(권장, 이미 reports.json 에 있음) / 텔레그램 올린 날.
4. **흐름 숫자**: 섹터마다 1~3개 핵심 숫자를 사람이 정한다(권장) / 목표주가·투자의견만 공통으로.

## 7. 위험·주의

- `study.js`·`build_study.py` 는 원래 세션 소관이다. 화면·빌드는 그 세션이 하거나 사용자가 맡긴 세션 하나만 고친다.
- 종합 JSON 을 여러 세션이 동시에 고치면 덮어쓴다(11/19 반도체 사례). 생성기로 JSON 을 다시 만드는 방식은 쓰지 않고, 고칠 때는 파일을 읽은 직후 바로 쓴다.
- 기존 주소·색인 링크는 그대로 둔다. 카드 내용은 바꾸지 않고 `rep` 필드만 더한다.

## 8. 반도체 시범 결과 (2026-11-19)

정할 것 4개는 추천안으로 했다: 주별 묶음 · 주제 종합은 '주제' 탭으로 유지 · 표지 발간일 기준 · 반도체 흐름 숫자 = 삼성·SK 목표주가, 2027 영업이익, 2028 DRAM 가격.

- **원본** `study/flow/semi.json`(새 파일, 섹터마다 하나): 리포트 14건의 성격(메모리 전망·후공정·소재·인터커넥트·ASIC·전력)·시각(낙관 11·중립 2·신중 1)·한 줄 결론·핵심 주장·목표주가(변경 포함)·흐름 숫자.
  날짜·하우스·제목은 `study/reports.json` 그대로 쓰고, 표지에 월만 있는 NH 는 `date_used`(주가 기준일 11/6)로 놓았다.
- **빌드** `build_study_flow.py`(새 파일) → `public/data/study/flow/<섹터>.json` + `index.json`. `build_study.py` 끝에서 부른다(실패해도 본 빌드는 그대로).
  카드 연결은 자동: 그림 카드 → crops 의 리포트 키, 글 카드 → `src` 의 하우스 이름, 줄 → '하우스:'·'하우스(…):' 로 시작하는 줄. 반도체 카드 연결 310개, 줄 78개.
  **종합 문서 JSON 은 고치지 않는다** — 여러 세션이 같이 고치는 파일이라 흐름 쪽은 따로 둔다.
- **화면** `study.js`·`study.css`(흐름 절 추가), `study.html` 버전 문자열:
  - 섹터 첫 화면(`?n=semi`) = 탭 `흐름 14 | 주제 1 | 교재 6`. 흐름 파일이 없는 섹터는 지금 화면 그대로.
  - 흐름: 발간일 순 막대 5개(SK·삼성 목표주가, 2027 영업이익 둘, 2028 DRAM 가격) + 주별 리포트 목록(최근 주·최근 리포트가 위).
  - 리포트 보기(`?r=rg-14687`): 결론·핵심 주장·목표가·2028 시각, 흐름 숫자를 '앞선 리포트 평균'과 비교, 직전 같은 성격 리포트, 종합에서 이 리포트가 한 말(카드 링크), 이 리포트의 그림 카드, 출처로 적힌 카드 목록.
  - 문서 쪽 리포트 목록의 하우스 이름 → 리포트 보기, 첫 화면 섹터 칸에 '리포트 흐름 n'.
- 보이는 흐름(예): SK 목표주가 11/2 KB 350만 → 11/12 하나 280만(하향) → 11/16 키움 180만(하향, 앞선 8건 평균 309만보다 아래), 2028 DRAM 은 11/4 iM +3% → 11/16 키움 −54%.
