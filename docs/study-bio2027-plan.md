## 1. 만든 순서

1. 리포트별 요약: 다올·교보는 서브에이전트(지침 `study_src/bio-2027/_work/BRIEF.md`, 바이오용 태그), NH 장(19쪽)은 직접 읽음.
   → `_work/digest-daol.md` · `digest-kyobo.md`.
2. 그림 상자: `_work/capbox.py` 가 쪽 글자 위치에서 캡션 줄 ~ '자료:/Source:' 줄을 찾아 0~1 비율 상자를 만든다(눈대중 격자 대신).
   `_work/mkcrops.py`(NH) + `crops_more.py`(교보·다올) → `study_src/bio-2027/crops.json` → `python3 study_crop.py --doc bio-2027 [--sheet]`.
   같은 내용의 그림은 하나만(예: 인티스메란 RFS는 교보, ALK7 비교는 교보, AI 밸류체인은 NH, 에페·에피노페그듀타이드는 교보).
3. 생성기: `_work/lib.py`(카드 함수) · `t1.py`(업황·딜) · `t2.py`(정책·비만·특허) · `t3.py`(항암·AI·CDMO·일정) · `t4.py`(기업·밸류) · `main.py`(문서 + 빠진 색인 점검) · `ent.py`(색인) · `dia.py`(도식 SVG).
   ```bash
   cd study_src/bio-2027/_work && python3 -P ent.py && python3 -P dia.py && python3 -P main.py && cd ../../.. && python3 build_study.py
   ```

## 4. 원문 대조에서 고친 것·표시한 것

- **한미약품 영업이익이 하우스마다 크게 다름**: 2026E/2027F = 다올 391/383, 교보 284/303, NH 531/243(십억원). 다올·NH는 두 해 합이 같고(약 7,740억원) 배분만 다르다 → 기술이전 계약금 인식 시점 차이로 보이며, 이는 페이지의 해석이라고 표시.
- 국내 기술이전 2025년 규모: 다올 21.4조원(제약산업정보포털) vs 교보 27.7조원(한국바이오협회). 출처·기간 차이로 '견해 차이' 카드에 둘 다.
- 이보네시맙: NH(11/6)는 11/14 PDUFA 기대, 다올(11/17)은 CRL을 적음 — 늦은 쪽 사실 우선, 날짜 차이로 표시.
- ARO-ALK7 내장지방: 다올 그림 제목 13.6% vs 본문 14.1% → 위약 +0.5%를 빼면 같은 값(-13.6 − 0.5 = -14.1).
- 레타트루타이드 80주: 교보 28.3%(위약 미보정) vs NH 26.1%(위약 조정).
- 한올 시총 비율: NH 본문 24.1% vs 같은 쪽 시총 ÷ 이뮤노반트 9.9조원 = 18.8%. 한올 주가는 NH 11/6 35,700원 → 교보 11/16 50,800원(주식 수는 두 리포트에서 52.24백만 주로 일치).
- 교보 한미 3Q 매출 3,477억(본문) vs 3,774억원(표, YoY와 맞음), 한미정밀화학 연간 칸 복사 오류, SK바이오팜 3Q YoY 29.9 vs 34.8%.
- 다올 SK바이오팜 엑스코프리 2025 연간 621.7 vs 분기 합 630.4십억원, SOTP 순차입금(+131) vs 실적표(-429), 한미 '정상화 EBITDA' 정의 없음(4,636 ÷ 16 ≈ 290으로 역산).
- 다올 셀트리온 영업가치 71,143 vs EBITDA 2,845 × 25 = 71,125(반올림).
