## 2. 트리 (Study › 반도체 › 2027 전망)

한눈에 보기 → AI 수요 → DRAM → HBM → NAND·eSSD → 공급·설비투자 → 파운드리·첨단 패키징 → 후공정·테스트 → 장비·소재 → 인터커넥트·전력·ASIC → 피크아웃 논쟁 → 실적·밸류에이션.
수요 → 메모리 3품목 → 공급 → 제조 체인 → 숫자를 다 본 뒤 논쟁과 밸류에이션 순서. 책 기반 기존 노드(memory/hbm 등)는 건드리지 않고 색인 키로 이어진다.

## 4. 원문 대조에서 고친 것·표시한 것 (카드 `add` 에 밝힘)

- iM: 그림 70 제목 'SK 56%' vs 라벨·표 53%(53%로 씀).
