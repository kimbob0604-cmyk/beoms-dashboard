# 실적 발표 덱 · 서프/미스 반응 추적 계획 (2026-11-12)

## 목표
공시 탭에서 실적 공시를 **매출 서프 / 영업이익 서프 / 미스**로 나눠 카드덱으로 보고, 발표 시각(초 단위)부터 주가가 어떻게 움직였는지
분봉으로 따라간다. 과거 사례를 모아 "이런 실적이 이 시간대에 나오면 평균적으로 어떻게 반응했나"를 보여 준다.

## 확인한 것 (실측)
| 항목 | 결과 |
|---|---|
| @darthacking 채널 | 사용자 텔레그램 계정으로 읽힘. 2021-02 부터 모든 공시를 올리고, 실적 글에는 감지 시각(초)·시총·매출/영업익/순익 실제치·예상치(차이 %)·최근 5분기가 있다. 형식이 두 가지(2023 무렵 `매출: X(예상치: Y)`, 지금 `매출액 : X(예상치 : Y, +Z%)` + 종목코드) |
| 예상치 | 예상치 없는 종목은 `-`(지금) 또는 `0억`(예전) — 비교 대상에서 뺀다 |
| 중복 | 잠정실적 뒤 분기보고서에도 같은 숫자가 다시 올라온다(`잠정실적 : Y`) → 첫 발표만 이벤트로 |
| KIS 과거 분봉 (`FHKST03010230`) | 약 1년 전까지(2025-11-12 됨, 2024-11-12 빈 응답). 한 번에 120분. 통합(UN)이면 넥스트레이드 08:00~20:00 포함 |
| 일봉 | history.db `hp`(2005~, 등락률로 수정주가 이음)·`hidx`(코스피·코스닥 지수) |

## 데이터 흐름
1. `collect_earn.py posts` — 채널에서 `예상치`가 들어간 글을 서버 검색으로 받아 파싱 → `db/earn.db` `earn_post`
   (글 id, 감지 시각, 종목코드, 이름, 시총, 보고서, 잠정 여부, 매출·영업익·순익 실제/예상). 이후엔 마지막 글 id 뒤만.
2. `collect_earn.py minutes` — 최근 1년 이벤트마다 KIS 통합 분봉: 발표일 08:00~20:00, 장후 발표면 다음 거래일 08:00~15:30도.
   `minute_day`(종목·날짜별 [시각, 종가, 거래량] JSON). 이미 받은 날은 건너뛴다.
3. `build_earn.py` — 이벤트 확정·판정·반응 계산 → `public/data/earn/{date}.json`(그날 카드), `earn/stats.json`(과거 평균), `dates.json`.

## 판정
- 매출 서프/미스: 예상치 대비 ±5%. 영업이익: ±10%, 또는 적자 예상→흑자(서프)·흑자 예상→적자(미스).
- 덱 묶음: **동반 서프**(매출·영익 둘 다) · **영업이익 서프**(매출은 서프 아님) · **매출 서프**(영익은 서프 아님·미스 아님) · **영업이익 미스** · 부합.
- 시간대: 장전(<09:00) · 장중(09:00~15:20) · 장후(≥15:20, 넥스트레이드 애프터마켓에서 먼저 반응). 주말·휴장일 발표는 다음 거래일 장전.

## 반응 지표
- 분봉(최근 1년): 기준 = 발표 직전 마지막 체결가(장중) / 그날 정규장 종가(장후) / 전날 종가(장전).
  +5분·+30분·+60분, 장후면 넥스트레이드 20:00 마지막 가격, 다음 거래일 시가·종가.
- 일봉(2021~): 반응일 시가 갭, 반응일 종가, D+1·D+5·D+20 누적 — 같은 시장 지수를 뺀 초과수익도.
- 통계: 묶음 × 시간대별 건수·평균·중앙값·오른 비율. 장중 발표는 발표 후 −30~+120분 평균 경로 차트.

## 화면 (공시 탭)
- 맨 위 **실적 발표 덱**: 그날 발표를 묶음별 열로. 카드 = 종목·시총·발표 시각·시간대, 매출/영익 실제 vs 예상(차이 %), 반응 숫자,
  발표 시각 표시가 있는 그날(장후면 다음 날까지) 분봉 미니 차트.
- **서프·미스 반응 통계**(접이식): 묶음 × 시간대 표, 장중 평균 경로 차트.

## 운영
- daily(아침·저녁): posts → minutes(새 이벤트만) → build_earn. live(장중 10분): posts 만 받고 그날 이벤트의 분봉을 갱신(1~2분 지연).
- 텔레그램 세션이 없으면 4로 건너뛴다. KIS 호출은 초당 9회 안팎.
