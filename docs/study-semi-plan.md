바이오(`docs/study-plan.md`)와 같은 방식으로 책 한 권을 그림·표·설명 카드로 분해해 **Study › 반도체** 가지에 쌓는다.
목적은 공부다. 쉽게 이해되도록 원본 그림을 다듬어 넣고, 핵심 기술은 짚어 가며 설명하는 해설(`tech`)을 붙이고, 차트는 숫자를 읽어 다시 그린다.
**[결정]**은 정해야 할 것, **[확인 필요]**는 실측이 남은 것이다.

## 1. 분류 트리 (Study › 반도체)

트리는 **주제 기준**이다. 나중에 HBM 리포트가 오면 같은 「메모리 › HBM」 가지에 붙는다.
책 순서와 거의 같지만, 「한 걸음 더」 꼭지는 주제가 맞는 가지로 옮긴다.
예를 들어 FinFET·GAA는 「소자 미세화」로, CMP는 「금속 배선·평탄화」로, MCU는 「기타 시스템 반도체」로 간다.

2. 집적 방법: 1-20(면적)·1-21(적층)·1-22(축소+조합) 25→100→400개
3. 잉곳에서 웨이퍼로: 3-9 잉곳 → 3-10 트리밍·소잉 → 3-11 엣지 라운딩·래핑·에칭·폴리싱
4. 산화막의 세 자리: 3-15 STI → 3-16 ILD → 3-17 IMD
5. 포토 8단계: 3-23 흐름 + 3-24 코팅 → 3-25·3-28 노광 → 3-30 현상 → 3-31 양성·음성 → 3-32 에칭

7. **N-MOSFET 8대 공정 17컷**: 책 p.265–276. 이 가지의 핵심 카드. 공정을 다 배운 뒤 처음부터 끝까지 따라간다

### 2-2. 노드별 카드 (그림 → 처리)

**기초 (그림 25 + 표 1 → 카드 약 40)**
- 1-1·1-2 전류·자유 전자: 원본 정리본 2장. 해설 「전류 방향 관례(+→−)는 책과 반대」
- 1-3 원자 구조(Si 2-8-4): tech로 부위 설명(원자핵·최외각·최외각 전자)
- 1-4~1-9: 단계 넘기기 ①. 1-8/1-9에 「정공은 양전하처럼 움직인다」 해설을 덧붙인다(책 외)
- 1-10·1-11·1-15 사진: 원본 정리본. 진공관·트랜지스터 실물은 공개 이미지 후보
- 1-12 PN 접합 정류, 1-13 BJT, 1-14 MOSFET, 표 1-1 소자 비교: **MOSFET 해설 카드**(게이트 전압 → 채널 형성 → ON/OFF, 3단계)를 별도로 만든다
- 1-16 미국 직통 전화(4,000km), 1-17·1-18 이진수(11110₂=30, 101₂+10₂=111₂): 원본 + 계산을 숫자로 풀어 쓴다
- 1-19 납땜 회로 vs IC: 원본 + 「킬비 IC는 실제로 저마늄 위」 검토 메모
- 1-20~1-22: 단계 넘기기 ②
- 1-23 선폭, 1-24 웨이퍼당 칩(72 vs 256): 원본 + **노드 이름은 실제 길이가 아니다** 해설(책 외)
- 1-25 Planar·FinFET·GAA: **tech 해설 대표 카드**. 고무호스 비유, 누설 전류. 2026 현황은 §4로 이어진다

**시스템 반도체 (그림 18 + 표 4 → 카드 약 35)**

- 2-7 GPU 블록, 2-8 셰프 4명 vs 알바 5,000명: 원본 + CPU·GPU 비교 해설
- 2-10 AP 칩 평면도: tech로 블록마다 점(CPU·GPU·NPU·모뎀·ISP)
- 2-12 AI·ML·DL 벤, 2-13 NPU, 2-14 FPGA, 2-15 ASIC, 표 2-2~2-4: 표 카드 3장. 검토 메모로 「표 2-3 전력 순서 뒤바뀜」, 「표 2-4 세대 구분은 책 고유 분류」

## 3. 검토 메모 (책 오류·낡은 서술) — 카드에 「검토」 표시로 남긴다

바이오 때처럼 본문은 책대로 정리하고, 의심 가는 곳에는 해당 카드에 검토 메모를 붙인다. 주요 항목:

- **숫자·순서**
  - 표 4-1: 인텔 83.4조가 삼성 83.2조보다 큰데 2위로 표기되어 있다
  - NAND 순위: SK하이닉스 19.5%가 3위, 키옥시아 19.2%가 2위로 뒤바뀌어 있다
  - 웨이퍼 일본 점유율: p.309는 49%, p.321은 54.6%로 다르다
  - 메모리 시장 합: DRAM 925 + NAND 555 ≠ 1,538억 달러
  - 표 2-3: FPGA·ASIC 전력 순서가 본문과 반대다
  - 표 4-2: 케이던스 0.36조·시놉시스 1.24조는 IP 부문만인 것으로 보인다
- **사실 확인**
  - 플레밍 2극관 1905 → 통설은 1904
  - 킬비 IC 「세라믹 판」 → 실제는 저마늄 위
  - 일본 수출 규제 「2020년」 → 2019년 7월
  - 「1983 삼성 한국반도체 인수」 → 1974년
  - 삼성 DRAM 1위 「1998년」 → 통상 1992년
  - 자일링스 인수는 발표 2020, 완료 2022
- **책 오타**: TSCM, 엔디비아, 도코 일렉트론, 표 3-3 「PVC」, DDR 「Dual」, CIS 「Complimentary」, 앰코/엠코 혼용
- **단순화 경고**
  - 노드명 = 실제 길이로 서술함
  - 전류 = 전자 흐름으로 서술함
  - 「사이클은 메모리에만 있다」
  - 「산화 공정 중요도 하락」
  - ROM을 C드라이브로 설명함
- 출처 확인이 필요한 항목은 **[확인 필요]**로 둔다. 인벤토리 파일의 「오류 의심」 절에 총 약 90건이 있다
