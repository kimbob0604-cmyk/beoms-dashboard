# Beom's China — 새 중국 대시보드 계획 (2026-11-26)

사용자 요청: 디시 글의 '돼지 사이클 → CPI' 논리를 중국 트래킹 지표로 체계화한다. Beom's Macro 의 탭이 아니라 **새 사이트**로 만든다. 해외 IB 중국 애널들이 어떻게 정리하는지 먼저 조사.
조사 원고: `docs/research/china-ib-macro.md`(IB·연준·독립 리서치의 경기 추적 틀) · `docs/research/china-hog-analysts.md`(양돈 애널 틀·최신 숫자) · `docs/research/china-dashboard-sources.md`(공개 대시보드 구성·무료 데이터 실측). 돼지 칸 초안은 `docs/china-pig-plan.md`.

## 1. 조사에서 배운 것 — 하우스들은 이렇게 본다

- **합성 활동지수 하나를 맨 위에 둔다.** 공식 GDP를 믿지 않고 실물 지표로 직접 만든다.
  - Goldman CAI: 실물지표의 제1주성분(PCA), 산업생산·전력·PMI 등.
  - SF Fed CCAT: 8개 — 소비자심리·전력·수출·고정투자·신규착공·산업생산·철도화물·소매.
  - Capital Economics CAP: 공식 GDP·산업생산·소매를 빼고 제품 생산량·건설기계·택배·주택판매·승용차 등.
  - 리커창 지수: 전력·철도화물·은행대출.
  - Rhodium 은 지출 항목으로 다시 계산해 2025 성장률을 2.5~3.0%로 본다(공식 5.2%).
- **신용 임펄스로 6~12개월 뒤를 본다**(NY Fed: TSF 흐름 변화 ÷ GDP, TS Lombard: M1). 정확한 시차 숫자는 공개 출처로 확인 못 함 — 우리 데이터로 직접 재 본다.
- **물가는 명목 GDP·디플레이터까지** 본다(Macquarie: 기업이익은 명목 GDP 와 같이 움직인다).
- **양돈 애널(중국 증권사 중심)의 사이클 판단**:
  - 공급 선행: 능번모돈(정상 보유량 대비 %). 2026년 5월 정상 보유량 3,750만 두, 녹색 92~103%, 황색 88~92%·103~106%(원문 확인 필요, 3,650만 하향설도 있음).
  - 바닥 확인 4조건: 모돈 감소 지속 + 출하 체중 하락 + 냉동 재고 하락 + 도태 모돈 할인율 70% 하회(감산 가속).
  - 수익성: 저량비(5 미만 1급 경보) · 자번자양 두당 손익 · 상장사 완전원가(무위안 2026-09 11.5위안/kg 미만, 원스 12.1).
  - 적자 기간: 이번 사이클 약 14개월(과거 9~12개월) — 길수록 감산이 깊다.
  - 밸류: 업종 PBR 밴드(신만 양돈 3.2배, 11/7), 두당 시가총액 2,000위안 미만 = 저위(CITIC).
  - 해외 IB(Goldman·Morgan Stanley)는 2027 돈가 13.6~15.3위안/kg 가정 — 지금(9~10위안)보다 높게 본다.
- 공개 대시보드의 공통 순서: 합성지수 → 성장 → 물가 → 통화·신용 → 무역 → 부동산 → 금리·환율·증시 → 고빈도.

## 2. 사이트 구성 (탭)

| 탭 | 무엇을 | 대표 지표 | 신호 |
|---|---|---|---|
| 오늘 | 국면 한눈에: 성장·물가·신용·부동산·돼지 다섯 줄 + 오늘 바뀐 것 | 각 탭의 대표 숫자와 방향 | 국면 전환 시 텔레그램 |
| 성장 | **자체 활동지수**(CCAT 8개 중 무료로 되는 것 + 리커창 지수) vs 공식 GDP | 산업생산·전력·소매·고정투자·수출·PMI·철도화물 | 활동지수 0선 교차 |
| 물가·디플레 | CPI·근원·PPI·디플레이터(명목−실질), **돼지가 CPI 에 준 기여** | CPI 세부, PPI, 명목 GDP | 디플레이터 플러스 전환 |
| 돼지 사이클 | 글의 논리 + 애널 틀 9칸(`docs/china-pig-plan.md`) + 바닥 4조건 판정 | 모돈·저량비·현물·선물·원가·자돈·수매 | 저량비 경보 단계, 바닥 조건 충족 수 |
| 신용·정책 | **신용 임펄스 직접 계산**, M1−M2 갭, 신규대출 vs 정부채, LPR·10년물, PBoC 순유동성 | TSF(7개월 늦음 → 대출+정부채로 대체 계산) | 임펄스 바닥 반등 |
| 부동산 | 70도시 가격, 판매·착공·투자, 재고 | NBS 월간 | 가격 하락폭 축소 |
| 대외·원자재 | 수출입 금액, 원자재 수입 수량, 컨테이너 운임(SCFIS 선물), 철근 재고 | 해관·대련/상해 선물 | 수입(내수 대리) 반등 |
| 시장 | CSI300·항셍테크·CNY·10년물, 업종(양돈·소비·부동산), 한국 중국 관련주 연결 | yfinance·동방재부 | — |
| 지표 사전 | 각 지표의 출처·주기·지연·계산식·어느 하우스가 쓰는지 | — | — |

모든 칸은 Beom's Macro 처럼 '지금 읽으면' 한 줄 + 과거 근거(신호 뒤 CSI300·양돈주 수익률 vs 아무 날) + 계산식 공개 + 가정 입력칸.

## 3. 데이터 (실측 결과 요약 — 서울 IP 기준)

- 됨(akshare·동방재부): CPI·PPI·PMI·산업생산·소매·고정투자·70도시 주택가격·신규대출·M1·M2·해관 수출입·LPR·국채·전력.
- 됨(선물·시세): 생돈 LH·옥수수 C(Sina), 컨테이너 운임 선물 EC0, 철근 재고, 돼지 현물·옥수수(玄田), yfinance(CSI300·HSTECH·CNY·양돈주).
- 늦음: TSF 7개월 지연(상무부), 모돈 수·공식 저량비·자돈가 무료 출처 수개월 지연 → 계산 대체 또는 월 1회 수동 입력.
- 안 됨: NBS 데이터 포털(403) → 발표문 HTML 파싱, 고빈도(지하철·석탄·30도시 주간 주택거래)는 무료 API 없음 — 1차에선 뺀다.
- **미국 IP(GitHub Actions)는 전부 미확인.** 첫 단계에서 출처마다 클라우드 접속 시험을 하고, 막히는 것은 맥에서 받아 DB 로 올리는 혼합 방식(Macro 의 seed 방식)으로.

## 4. 만드는 방법

- 새 폴더 `~/Beom's China`, 새 저장소 `beoms-china`(만들기 전 사용자 확인), 주소 kimbob0604-cmyk.github.io/beoms-china/.
- Beom's Macro 뼈대를 그대로 가져온다: 수집기 → SQLite → 빌드 JSON → 정적 화면(mu.js·mchart.js), 암호 배포(site_crypt), 클라우드 수집(daily.yml)·DB 이어 주기(sync.py), 텔레그램 정기 보고(차트 캡처).
- 텔레그램은 @beomjun_report_bot 또는 새 봇(사용자 선택).

## 5. 단계

1. **뼈대 + 출처 시험**: 저장소·폴더, 수집기 1차(물가·성장·신용·돼지 현물/선물·시장), 클라우드 접속 시험표. → '오늘'·'돼지 사이클'·'물가' 탭.
2. 성장(자체 활동지수)·신용(임펄스)·부동산·대외 탭, 과거 근거.
3. 모돈·수매 등 늦는 자료 수집 경로(농업농촌부·발개위 공지 파싱 또는 월 입력), 바닥 4조건 판정, 국면 알림, 텔레그램 정기 보고.

## 6. 확인 필요 (조사에서 못 닫은 것)

- 정상 보유량 3,750만 vs 3,650만, 저량비 경보 최신 預案 기준선 — 농업농촌부·발개위 원문.
- 돼지고기 CPI 가중치(2022년 사례 역산 약 2.3%, 추정).
- 해외 IB 양돈 틀은 Goldman·MS 2차 요약만 — 원문 없음.
- 신용 임펄스 → 원자재·성장 시차(우리 데이터로 측정해 화면에 근거로 쓴다).
