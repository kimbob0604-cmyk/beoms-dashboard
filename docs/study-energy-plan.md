## 1. 만드는 순서

1. `study_tg_fetch.py` 로 PDF 받기 → 리포트별 요약(digest) 8개.
2. 종합 설계: 트리, 주제별 합의/견해 차이/하우스만의 시각, 숫자 맞대기 표, 그림 숏리스트(대체 가능한 중복 그림은 버림), 도식 후보, 충돌·오류 목록.
3. 그림 44개를 쪽 사진(10% 격자)에서 상자로 잡아 `study_src/energy-2027/crops.json` → `study_crop.py` → 접촉 시트로 검수.
4. 트리(`study/tree/energy.json`) · 색인(`study/entities/energy.json`, 개념 42·기업 31(+기존 솔브레인)) · 도식 SVG 6개 · 문서(`study/docs/energy-2027.json`).

## 4. 원문 대조에서 고친 것·표시한 것

- 신한 p.18 "공제의 40%를 고객에 배분하면 79달러" — 숫자(65 + 35×40% = 79)는 셀사가 40%를 갖는 경우와 같다. 숫자가 맞는 쪽으로 적고 덧붙임에 밝혔다.
- 미래 p.8 본문 "포스코퓨처엠 27년 65%" — 그림의 2027F 막대는 약 55%, 65%는 2028F. 그림 값으로 쓰고 표시.
- 대신(10월) 1H26 북미 ESS 점유율 — 합이 100%를 넘어 DB 값으로 대체.
- 메리츠 셀 2사 합산에서 역산한 삼성SDI 0.57조원 — 다른 하우스와 너무 달라 범위에서 제외.
- 행정명령 번호 14421/14420 혼용 — 날짜로만 적음. 블루웨이브 확률 그림은 출처 표기가 없다고 표시.
- 유안타 관세표·캘린더는 화면 설명을 원본 칸 이름에 맞게 고침(2027.12.31은 태양광·풍력 발전 공제 가동 시한).
