## 4. 견해 차이·원문 대조에서 표시한 것

- **하이브 2027 실적**: 교보 매출 3.81조(−20.9%)·영업이익 0.44조 vs NH 5.14조(+2.2%)·0.61조. BTS 투어 매출의 시점 가정 차이(교보는 추가 활동 미반영). POR 15.7배 vs 10.4배.
- **CORTIS 판매량**: 교보 'GREENGREEN' 435만 장 vs NH 초동 230만 장·미니2집 252.5만 장(써클차트). 집계처·기간 차이로 보이며 확인 불가로 표시.
- **2027 신인**: 교보는 성장 동력, NH는 이미 데뷔한 5세대의 수확기를 강조(신인 데뷔는 2024~25 마진 압박 논리).
- 교보 요약(p.3) 영국 수출 +111.7% vs 본문(p.22) +111.1% → 본문 값.
- 교보 에스엠 상승여력 48.9%는 적정주가(112,000원) 기준, 목표주가(110,000원) 기준은 46.3%. 기업가치 2,566.2 vs 132.0×19.4 = 2,560.8(순이익 반올림).
- NH 광고시장: 플랫폼 장(광고연감) 2026E 16.5조 vs 엔터/미디어 장(KOBACO) 17.9조 — 같은 하우스 안 출처 차이.
- NH p.94 표는 2022년에도 노출형(4.16조) > 검색(3.95조)이라 본문 '2021년 외엔 검색이 항상 높았다'와 맞지 않음 → 카드에 표시.
- NH NHN 시총 1.9조(p.90, 11/6) vs 2.50조(p.100, 11/10) — 기준일 차이.
