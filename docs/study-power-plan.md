## 1. 만드는 순서 (작업 파일: `study_src/power-2027/_work/`, 로컬)

1. 리포트별 요약 `digest-<글번호>.md` 13개(서브에이전트, 지침 `BRIEF.md` — 주제 태그를 전력용으로 바꿈). 도구 `rgdump.py`(쪽 글, OCR 포함)·`rgpage.py`(쪽 PNG).
2. 종합 설계 `synthesis.md`: 트리, 합의/견해 차이/숫자 맞대기, 그림 숏리스트(후보 85 → 51), 도식·계산 카드 목록, 충돌·오류 목록.
3. 그림: `gridsheet.py`로 10% 격자 쪽 시트 → `mkcrops.py` → `study_src/power-2027/crops.json` → `python3 study_crop.py --doc power-2027` → `--sheet` 검수(제목 잘림 15개 고침).
4. 트리·색인 `ent.py` → `study/tree/power.json`, `study/entities/power.json`(개념 37 + 기업 43, 재사용: 효성·LS ELECTRIC(2차전지), Amazon·Microsoft·Alphabet·Meta·CoreWeave(반도체)).
5. 도식 `dg.py` → `study/diagrams/power-*.svg` 6개(글자 폭 어림 검사로 넘침 0, 화면에서 SVG getBBox로 다시 확인).
6. 카드 `p1.py`~`p3.py` + `main.py` → `study/docs/power-2027.json`. `python3 build_study.py` 오류 0.

## 2. 트리 (Study › 전력·원전·신재생)

시장 지도 → 전력 수요(AI DC·반도체) → 계통·전력시장 → 전력기기 → 원전(미국·SMR·한국) → 가스터빈·연료전지·EPC → 태양광·풍력 → 유틸리티(한전·발전) → 기업·밸류에이션 → 연료비·정유(요약).
수요 → 길(계통) → 길에 들어가는 기기 → 발전원 → 비용을 내는 쪽 순서. 숫자를 다 본 뒤 밸류에이션.
